# Studies

I do data analysis on chess because I find it interesting.

Each study takes one question about how people play chess and answers it from the 8 billion games Lichess has made public.  
[The Lichess Data page](/how-the-data-is-checked.html) shows where those games come from and how I validated my data.

I'm really excited to keep adding to this!
