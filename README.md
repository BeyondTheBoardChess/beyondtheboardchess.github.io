# Beyond the Board: the data behind the videos

Hi, and thanks for coming!

Every number I put on screen came from somewhere, and this is where you can check any of it for
yourself.

Lichess lets anyone download the games played on it. I downloaded those files once, kept them
exactly as they came, and everything in my videos comes from them. I've checked them against what
Lichess actually published, month by month, and you can
[read exactly how](how-the-data-is-checked.md).

Once a video goes up, it gets a folder of its own here with the question it asked, the games it
used, and how every number on screen was calculated.

Thanks for watching my channel :)

## What's in here

You don't need an account, nothing here needs downloading, and none of it is code you have to run.
Every page below opens in your browser, and its name says what it holds.

| Open this | To read |
| --- | --- |

| a folder named after a video | the question that video asked, and how every number in it was calculated |
